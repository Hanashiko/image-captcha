# 🖼️ Image CAPTCHA Generator

Простий генератор зображень CAPTCHA на Python з кастомним текстом, шрифтами та розмірами. Побудований на основі бібліотеки [`captcha`](https://pypi.org/project/captcha/) з підтримкою рендеру через `PIL`.

---

## 🔍 Опис

Скрипт створює CAPTCHA-зображення зі вказаним текстом, зберігаючи результат у памʼяті або, за потреби, у файл.

---

## 🛠️ Технології

- [`captcha`](https://pypi.org/project/captcha/) — для генерації зображення CAPTCHA
- `Pillow (PIL)` — для роботи з зображенням
- `io.BytesIO` — для роботи з байтовим потоком зображення

---

## 🧪 Приклад використання

```bash
python main.py
```
> Після запуску відкриється CAPTCHA-зображення зі словом HANASHIKO.

## 🖋️ Налаштування
### ✅ Текст
Текст CAPTCHA можна змінити у змінній text:
```python
text: str = "HANASHIKO"
```
### ✅ Шрифти
Шляхи до шрифтів задаються вручну в конструкторі:
```python
fonts=['./fonts/Anton.ttf', './fonts/BodoniModaSC.ttf', ...]
```
> ⚠️ Переконайтесь, що всі вказані шрифти існують у директорії ./fonts.
### ✅ Розміри шрифтів
Кастомний діапазон розмірів шрифту:
```python
font_sizes=(40, 70, 100)
```
## 💾 Збереження у файл
Для збереження зображення у файл розкоментуйте рядок:
```python
captcha.write(text, 'captcha.png')
```
